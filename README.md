# median-to-mean-reproducible

Validation archive for the allmeta **median-to-mean** app (estimating a mean and SD from a median with range and/or IQR:
Wan et al. 2014, Luo et al. 2018, Shi et al. 2020), compared with R.

## One command

```
Rscript --no-environ validate.R [--lib=PATH_TO_R_LIBRARY]
```

Prints per-quantity tables and `PASS N/N` / `FAIL k/N` for each capture, then `VALIDATION PASSED` (exit 0) or
`VALIDATION FAILED` (exit 1). It fails closed if R is not 4.6.0, if jsonlite 2.0.0, metaBLUE 1.0.0 or estmeansd 1.0.1 are not
the installed versions, if `corpus/grid.csv` is not regenerated byte-for-byte by `R/gen_grid.R` with the pre-registered seed,
if the corpus counts differ from the pre-registration, or if any configuration is missing or extra.
The original page is expected to fail (it is reported, not gated); the fixed page, the metaBLUE cross-check and the worked
example must pass. `Rscript --no-environ validate.R --planted` runs the planted-defect tests (each must make the gate fail).
`node verify_archive.js` checks every file hash (MANIFEST.sha256), the app snapshots and the provenance of the captures.

pages give bit-identical outputs (`results/original_vs_fixed.txt`).

## Re-capturing the app outputs

```
cd harness && npm ci            # jsdom 25.0.1
node harness/make_cases.js
node harness/run_app.js app/fixed/median-to-mean/index.html harness/cases.json captured/app_fixed.json
node harness/run_app.js app/original/median-to-mean/index.html harness/cases.json captured/app_original.json
node harness/run_app.js app/fixed/median-to-mean/index.html harness/cases_worked.json captured/worked_fixed.json
```

Captured with Node.js v24.22.0 on Windows 10.

## Scope

- Estimators: Wan 2014 mean and SD (C1 five-number, C2 min/median/max, C3 IQR), Luo 2018 mean (C1–C3), Shi 2020 SD (C1;
  C3 = Wan). The app's labels differ from Wan 2014's: app C1 = Wan's C2 (five-number), app C2 = Wan's C1 (three-number).
- Reference: the published closed forms in base R (R's `qnorm`), and metaBLUE 1.0.0 (`Luo.mean`, `Wan.std`).
- Checked: the hook values, every exported mean and SD, every displayed table cell (as text), warnings and refusals.

## Limits

- Distribution-based methods (estmeansd QE, BC, MLN; Hozo; Bland; BLUE) are not implemented by the app; QE and BC are shown
  for the worked example only as a descriptive comparison.
- The worked examples printed in Wan 2014, Luo 2018 and Shi 2020 were NOT checked: the source texts could not be read in the
  validation environment (no literature access). The pre-registered stratum is empty (`corpus/published.csv` absent).
- The worked example is metamedian's `dat.age` (Katzenschlager et al. 2021, PLOS One 16:e0255154); the app is shown to agree
  with R on these reported medians, NOT to reproduce the meta-analysis's own converted inputs, which were not read.
- The page ran in Node.js + jsdom, not in a browser, for the counts; the figures come from Microsoft Edge 155 (headless).
- Normal-quantile edge: n up to 10¹² was probed; beyond the probed range, behaviour is untested.
